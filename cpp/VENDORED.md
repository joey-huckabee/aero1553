# Vendored dependencies

The C++ implementation has **no runtime dependencies**. This file records the
one test-only dependency, which is vendored as a pinned single header rather
than fetched at build time.

That choice mirrors the Rust crate's single-dependency discipline and the
Python package's stdlib-only parsing: argument parsing, CSV writing, TOML
config, logging and error types are all hand-rolled here too. See ADR-0001 for
why the toolchain floor makes fetching dependencies at build time a poor trade
in this tree specifically.

### Why v2 and not v3

Catch2 v3 requires **C++14**. The toolchain floor here is C++11 on GCC 4.8.5
(ADR-0001), so v3 is not an option regardless of its merits — the v2 line is
the last that compiles on the SLES 12 system compiler. v2.13.10 is the final
v2 release.

This is one of the recurring costs ADR-0001 names: the platform target, not the
library, is what rules a modern version out.

### Rules

- **Do not edit this file.** It is 650 kB of generated, merged upstream source;
  a local edit is invisible in review and lost on the next bump.
- It is included via `-isystem third_party` in the Makefile and via a `SYSTEM`
  include directory in CMake, so its own warnings cannot trip `-Werror` / `/WX`.
  Removing that would make the warning gates unusable rather than stricter.
- To bump: replace the file, update the version and SHA-256 above, and run the
  full suite on **both** the modern tier and the `gcc:4.8` fidelity tier. A
  Catch2 release that quietly requires a newer compiler fails only on the
  latter.

Verify the pin at any time with:

```bash
sha256sum cpp/third_party/catch2/catch.hpp
```
